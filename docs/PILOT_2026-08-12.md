# Pilot kolekcji — odczyt 2026-08-12

Źródła: `pilot-kolekcji.json` i `pilot-kolekcji.csv` wyeksportowane z panelu pilota iOS.
Oba pliki są ze sobą zgodne: 134 z 134 wartości CSV odpowiada raportowi JSON
(poza zamierzonym zaokrągleniem do 6 miejsc), a 132 zachowane zdarzenia dają
dokładnie 31 prób katalogowania, 75 etapów lookupu, 22 wyniki lokalizacji i 4
mutacje. Raport nie zawiera tytułów, ISBN, lokalizacji ani identyfikatorów
egzemplarzy.

## Decyzja produktowa po odczycie

1. Przed seryjnym skanowaniem wymagamy wyboru bieżącej półki i zachowujemy ją
   dla kolejnych obiektów; półkę można zmienić ze skanera.
2. Po kodzie 977 pokazujemy od razu ścieżkę prasy: jasny komunikat o tytule,
   widoczne OCR oraz wymagany numer, data albo dodatek EAN.
3. Jeżeli seria o tym ISSN/EAN-977 jest już w kolekcji, uzupełniamy wyłącznie
   jej wspólny opis. Numer, data, tom, kod i okładka nie są kopiowane.
4. Następny pilot powinien objąć co najmniej 20 numerów prasy, 5 półek, 20
   wyszukiwań oraz dwa pełne round-trip iOS → WWW → iOS.

## Ważne rozróżnienie eksportów

`raport-pilota-kpi.json/csv` służy do analizy KPI i nie jest bazą kolekcji.
WWW przyjmuje eksport JSON z głównego menu kolekcji iOS, zawierający tablice
`publications` i `ownedItems`.
